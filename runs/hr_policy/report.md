# ForgeAI report — ShoreHR Assistant

**Brief:** I need an assistant that answers HR policy questions for our shore staff (office employees, not crew at sea). It should explain leave entitlements, how to apply for leave, travel and expense claims, and working-from-home rules. It should also be able to tell people their salary band and when payroll is processed. Keep it friendly and short, and it must never give legal or medical advice.

**Stopped because:** all eval cases pass

Nothing failed on this eval set. Treat this with suspicion: the eval set was generated by the same model family that answers, so it may be too easy. Spot-check with real users.

## Known limitations of this evaluation

- The eval set is generated from the documents by an LLM; key facts are verified to appear verbatim in the documents, but question quality is not human-checked.
- Key-fact matching is string/number based and can miss correct paraphrases (false fails).
- The LLM judge uses the same model as the agent; it can only veto a pass, never grant one, to limit self-preference.
- The optimizer tunes against the same eval set it is scored on, so the final score is optimistic.
